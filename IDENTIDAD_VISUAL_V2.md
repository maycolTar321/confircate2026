# Identidad visual V2 — Jóvenes en Misión SMP

## Dirección creativa
Una experiencia pastoral juvenil contemporánea: clara, cercana, serena y orientada al servicio. El diseño prioriza superficies blancas, fondos gris niebla, acentos verde bosque, tipografía legible y controles cómodos en móvil.

## Paleta
- Verde bosque: `#214C3B` — acciones principales y navegación activa.
- Verde profundo: `#16382D` — superficies institucionales oscuras, como el pie de página.
- Verde suave: `#E4EEE8` — etiquetas, estados y fondos secundarios.
- Blanco: `#FFFFFF` — tarjetas y superficies de lectura.
- Gris niebla: `#F6F8F6` — fondo general.
- Gris carbón: `#303632` — texto principal.
- Gris medio: `#68736C` — texto secundario.

El logo oficial conserva sus colores y transparencia originales; no se le aplica filtro ni se recolorea.

## Componentes
- Portada editorial ligera con acentos orgánicos sutiles, no una tarjeta oscura gigante.
- Cabecera compacta y logo proporcionado.
- Tarjetas de pilares con fotografía, contenido y CTA consistentes.
- Navegación inferior compacta y áreas táctiles cómodas.
- Espaciado adaptable, controles fluidos y consideración de `prefers-reduced-motion`.

## Puesta en marcha
1. Instala las dependencias con `npm ci`.
2. Ejecuta `npm run dev`.
3. Valida `npm run build` y `npm test` antes del despliegue.

La compilación debe verificarse en un entorno con las dependencias instaladas. Esta entrega no afirma que el despliegue de Vercel se haya actualizado.
